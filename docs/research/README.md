# Research Index

**Date:** 2026-11-02 · Produced during v1 planning using parallel research agents and public sources.

**Key takeaways**
- v1 focuses on three groups: blood sugar (diabetes, prediabetes, PCOS), the family health manager, and weight loss.
- Photo-of-label scanning plus a verdict for each family member is our main differentiator. Indian barcode databases are tiny.
- The rules engine must decide every verdict; the AI only explains it. Accuracy and trust are the main risks.
- CallMissed provides the LLM, vision, STT, TTS, WhatsApp and email. Supabase handles login, the database and storage.
- Competitor research uses public sources only. We do not reverse engineer competitor apps.
